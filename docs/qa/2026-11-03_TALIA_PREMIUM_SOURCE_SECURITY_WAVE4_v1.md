## Research context
- National Academies of Sciences, Engineering, and Medicine, *How People Learn II*, Chapter 7, research on specific formative feedback, not an inference that a novice actually committed a named misconception: https://www.nationalacademies.org/read/24783/chapter/9.
- National Academies, Chapter 5, retrieval, varied practice and explanation research: https://www.nationalacademies.org/read/24783/chapter/7.
- Cboe's VIX FAQ: https://www.cboe.com/tradable_products/vix/faqs; official expected volatility uses eligible SPX option inputs, not an independently authorized redistributable indicator clone.

## Source protections implemented
1. **A02:** Refuse learner summary objects containing unexpected keys such as raw grades or member identifiers; refuse teaching-pattern objects containing protected rubrics. Explicitly state a candidate misconception check is not an observed or verified error.
2. **E01:** Require point-in-time sources within a closed HTTPS reference-host policy; refuse credential-bearing URLs, custom ports, access tokens, source-body fields and unexpected learner progress fields. Preserve as-of and two-course prerequisites.
3. **E03:** Refuse additional private case attributes, mixed-member rows, future timestamps, duplicate case references and nonfictional rights. Return counts only, with no member identifiers.
4. **CI:** Add more than 200 deterministic negative and positive prototype scenarios to the exact source gate, without changing a premium release flag.

The source URL allowlist is defense-in-depth for research citations, not a statement that a URL's content is independently verified or a commercial redistribution right has been granted.
