## Controlling principle

This package does not overwrite the approved master inventory or earlier membership and learning policy. It adds **a proposed V1 development-scope crosswalk** for all 229 requirements; Owner-directed frozen product decisions remain controlling. A source path in the crosswalk is a verified **existing repository candidate**, not proof that the individual requirement is functional or released.

The original Foundation teaching promise is not reduced. The distinction between Foundation conceptual instruction and premium **authorized data integration** is explicit: Basic teaches with first-party source material and fictional/revealed examples. Advanced adds verified adaptive learner records; Professional adds secure replay and contextual chart operations; Enterprise adds governed cross-course research and reporting. Premium prototypes remain unreleased.
