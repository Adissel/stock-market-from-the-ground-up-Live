## Controlling correction

The owner clarified that Talia Market Tutor is an **existing-website-membership-only product**. Members must **not** be asked to obtain, connect, buy, fund or maintain API keys for Talia. The optional member-owned AI-key work implemented on November 1, 2026 was a misinterpretation and has been rolled back. Neither the prior design nor its tests are active product requirements.

Access is enforced by existing signed-in member accounts and edition entitlements. Free members remain eligible for Basic Tutor instruction under existing owner-approved restrictions. Source-grounded Tutor instruction does not need an external AI provider. Optional future site-controlled model inference, if ever authorized, is a separate infrastructure and budget decision; no member-owned credentials are part of that plan.

The existing website BYO integrations for **Tiingo and Alpaca market data** remain separate and are preserved.
