## 2. Actual user-visible design changes

This is an immersive near-black/cyan/violet/gold interactive network, not a chart recolor.

Four selectable graphical modes:
1. **Learning Journey** — original nine approved learning stages connected around the shared Learning Engine v3.3.
2. **Lab Network** — twelve visually interconnected competencies, using current 419 unique canonical Lab IDs, title metadata, and existing provisional instructional mapping. Does not assert graded competency mastery.
3. **Boot Camp Atlas** — ten source-authored study paths comprising seven original courses/247 authored day positions plus three controlled beta paths/27 authored positions, totaling 274 source positions; not automatic commercial publication or grade release.
4. **Indicator Intelligence** — Talia's original 61 indicator teaching guides plus 12 expansion briefs, with source-backed concept/formula/limits where available. No claim that all 73 are rendered price-chart studies; 16 have independently tracked computed prototype choices.

Controls: click-to-inspect node; draggable individual nodes; blank-background pan; zoom in/out/wheel; reset; text-searchable source node list; responsive sidebar + Talia explanation panel; accessible button labels and selection states. Source network metadata comes from existing public, authored education indexes; no passwords, private learning progress, protected grades, answer keys, brokerage data, subscriptions, or payments.

Implementation uses native JavaScript, CSS and SVG at **$0 new licensing cost**. It deliberately does not bundle the commercially licensed GoJS product or replace the approved Lightweight Charts/KLineChart/ECharts market charting systems.
