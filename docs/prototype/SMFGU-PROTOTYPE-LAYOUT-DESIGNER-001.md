## Controls and behavior
- Open **Edit page layout** on the protected Prototype Experience page.
- Select Cards / charts, Buttons / links, Labels, or Headings / text. Use the searchable **Page elements** list to select any registered visible item by name without having to drag. Click directly on an item for pointer selection, including canvas/SVG descendants. Use **Refresh element list** after switching modules or changing the displayed content.
- Change selected width/height in pixels, nudge in four directions, hide/show specific elements, undo or reset. Stored per page and desktop/tablet/mobile viewport band in this browser only (localStorage).
- **Hide prototype-only UI** hides staff framing without removing the actual interactive teaching, indicators, and charts. **Screenshot mode** also hides layout controls; press Escape to restore editing.
- VWAP transaction lesson and evidence inspector share a responsive grid when space permits; Talia instructor presentation is visually balanced against the Chart evidence panel. Mobile remains stacked.
- No persistent server layout, AI inference, progress record, official assessment, membership entitlement or payment is created.

## Limitations and verification
Visual dragging uses CSS pixel offsets and is intended for screenshots and UI direction, not as a responsive production layout definition. Overlapping elements can occur if dragged across occupied content. Use reset/nudge and separate viewport-specific drafts. Captured screenshots are Owner design feedback, not proof of production entitlement.
