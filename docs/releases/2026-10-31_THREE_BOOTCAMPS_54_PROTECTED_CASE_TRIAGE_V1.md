## Method

A live, read-only Supabase audit examined each protected case's four dimensions, unique prompt count, resolved private option keys, privately stored rubrics and per-option corrective explanations, reviewer attribution, publication status and two ambiguity-risk prompt patterns. This is engineering/editorial *screening*, not independent expert attestation. The entire inventory stays private and inactive. The instructor's separate 27-day Owner approval applies only to **ungraded instructional Beta**, not graded cases.

The audit found **216/216 scoring key references structurally resolve**. However, **53 of 216 prompts use a generic definition-input formulation** and **27 use a general independent-transfer formulation**. These patterns merit substantive review for *multiple reasonable answers*, especially when other options state true definitions or valid transfer tasks. Their presence is a *risk flag*, not proof of wrong scoring. A case is held if it lacks necessary rubrics, feedback, individual approval or if there is a fair-answer ambiguity risk.
